# Image Classifier (CIFAR-10)

A convolutional neural network that classifies images into 10 categories, trained on the CIFAR-10 dataset.

## What it does
Loads and normalizes the CIFAR-10 dataset, trains (or loads a saved) CNN model to classify images into: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.

## Tech
- Python
- TensorFlow / Keras
- matplotlib

## Run
```bash
pip install tensorflow matplotlib
python main.py
```
